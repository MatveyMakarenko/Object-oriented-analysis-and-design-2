# Лабораторная 4. 

Каталог Фильмов

Паттерн: Загрузка по требованию (Lazy Loading)


## Проблема:

Проблема заключается в том, что при работе с базой данных, содержащей большое количество фильмов, требуется загружать связанную информацию (отзывы, списки актёров, постеры высокого разрешения). Если использовать жадную загрузку (Eager Loading), то при запуске приложения происходит чтение всего объёма данных из БД. Это приводит к длительному времени запуска (холодный старт), высокому потреблению оперативной памяти (вплоть до OutOfMemoryError на больших коллекциях) и подвисанию графического интерфейса (UI Freezing) во время инициализации. Класс модели фильма обрастает зависимостями, и приложение становится неэффективным.
## Цель:
Разработать информационную систему с графическим интерфейсом (Каталог фильмов), которая оптимизирует использование ресурсов за счёт отложенной загрузки «тяжёлых» данных. Приложение должно запускаться мгновенно, загружая только базовую информацию (название, год), а связанные данные (отзывы, актёры) подгружать из базы данных только в момент, когда пользователь явно запросит их просмотр.
## Описание:
Система позволяет пользователю просматривать список фильмов и переходить к детальному просмотру конкретного фильма. Организация загрузки данных реализуется с помощью паттерна Загрузка по требованию (Lazy Loading):

•	Movie (Модель) — содержит основные атрибуты фильма (название, год, описание, постер) и методы для получения связанных данных.

•	ReviewsLoad — компонент-загрузчик, отвечающий за получение списка отзывов для конкретного фильма из БД.

•	ActorsLoad — компонент-загрузчик, отвечающий за получение списка актёров для конкретного фильма из БД.

•	Review / Actor — модели связанных данных (отзывы и актёры).

•	Database (DAO) — абстракция базы данных, выполняющая SQL-запросы.
