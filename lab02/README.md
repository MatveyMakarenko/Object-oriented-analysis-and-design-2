# Лабораторная 2. 
Диспетчер Умного Дома (SmartHome Hub)

Паттерн: Декоратор
## Проблема:
Проблема заключается в том, что расширение функционала устройств «Умного дома» требует создания множества комбинаций классов для каждой возможной конфигурации дополнительных функций. Пользователи хотят самостоятельно настраивать дополнительные возможности устройств (мониторинг энергопотребления, уведомления о событиях) без изменения базового кода устройств. Использование наследования для каждой комбинации функций приведет к росту количества классов, нарушению принципа открытости/закрытости (OCP), усложнению кода при добавлении новых функций и невозможности динамического изменения конфигурации функций во время выполнения.
## Цель:
Разработать информационную систему с графическим интерфейсом, позволяющую пользователю динамически добавлять расширенные функции к устройствам умного дома (мониторинг энергии, уведомления) без изменения базовых классов устройств, с возможностью визуальной настройки конфигурации декораторов и экспорта текущей конфигурации.
## Описание:
Система позволяет пользователю выбрать устройство (например, «Освещение», «Термостат», «Замок»), после чего динамически применить к нему набор дополнительных функций через декораторы:

•	Базовое устройство (Base Device) - основная функциональность (включить/выключить свет, установить температуру, заблокировать замок)

•	Декоратор энергосбережения (EnergySavingDecorator) - добавляет мониторинг потребления энергии и времени работы

•	Декоратор уведомлений (NotificationDecorator) - добавляет отправку уведомлений при изменении состояния устройства

Для каждого устройства определяется базовый интерфейс, который реализуется как конкретными устройствами, так и декораторами.

Процесс расширения функционала устройств реализуется с помощью паттерна Декоратор (Decorator):
1.	Device - абстрактный класс всех устройств, определяющий основные методы управления.
2.	Конкретные устройства (Light, Thermostat, Lock) реализуют базовую функциональность устройств.
3.	DeviceDecorator - базовый декоратор, хранящий ссылку на Device и делегирующий вызовы.
4.	Конкретные декораторы (EnergySavingDecorator, NotificationDecorator) добавляют конкретные функции к устройствам.
5.	Результат - гибкая конфигурация устройства с набором функций, отображаемая в GUI, которую можно экспортировать как отчёт (JSON).
В рамках одного сеанса работы программы пользователь может добавлять и удалять функции устройств без перезапуска приложения, формируя индивидуальную конфигурацию для каждого устройства.
